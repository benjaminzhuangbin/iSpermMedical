# iSpermMedical

Medical instrument software workspace.

## Nexus ADB Watchdog

Native Android daemons (C) that monitor / recover TCP ADB on RK3288 / Android 5.1.1.

| Version | Path | Purpose |
|---------|------|---------|
| 1.0 | [`NexusADBWatchdog/`](NexusADBWatchdog/) | Basic monitor |
| 1.5 | [`NexusADBWatchdog-1.5/`](NexusADBWatchdog-1.5/) | Diagnostic data collection |
| **2.0** | [`NexusADBWatchdog-2.0/`](NexusADBWatchdog-2.0/) | **TCP ADB auto-recovery (rate-limited)** |

**Run Version 2.0 from:** `NexusADBWatchdog-2.0/`
