## 一、系统总体架构与安全机制

本系统由 **PC 端公司专属制作/签发工具** 与 **Android 精子分析仪主控端** 共同构成：

```
      【公司 PC 核心保密端】                         【医院现场 / 客户端】
+-------------------------------+              +------------------------------------+
| 公司 RSA-2048 私钥 (绝不下发) |              |  Android 分析仪通用 APK (纯公钥)   |
| (company_signing_rsa_priv)    |              |  - 内置 COMPANY_PUBLIC_KEY_B64     |
+---------------+---------------+              |  - 内置 APP_MASTER_KEY_B64         |
                | (数字签名)                    +-----------------+------------------+
                v                                                 ^
    +-----------------------+                                     | (插入 USB 检验)
    |  制作交付物：加密 U 盘  | ------------------------------------+
    |  - QC-Video/          | (AES-256-GCM 密文帧)
    |  - manifest.dat       | (SHA-256 哈希清单)
    |  - license.dat        | (官方 RSA 防伪签名)
    |  - device_binding.lic | (仪器 CPU + USB 物理芯片 一机一盘绑定授权)
    +-----------------------+
```

### 三大安全底线
1. **防直接读取**：所有原始 30 张 JPEG 图像均被拆分并以 AES-256-GCM 封装进二进制 `.qcv`，Windows/Mac PC 无法直接打开或查看。
2. **防随意克隆拷贝**：如果客户把 U 盘全盘复制到普通 FAT32 U 盘，插上分析仪会被底层物理芯片序列号拦截（**提示：检测到非原装授权 U 盘**）。
3. **防跨机串用借用**：A 医院的质控盘插到 B 医院的分析仪上，会因 CPU 硬件指纹不符直接阻断（**提示：此 QC USB DISK 未授权用于本仪器**）。
4. **视频与授权解耦**：客户后续增加或删除某个视频，只需增删对应文件夹并更新官方签名，**绑定凭据 `device_binding.lic` 永久有效，无需重新绑定**！

## 四、生产场景实操指引

### 场景 A：新机出厂（制作视频同时完成一键绑定）
> **适用**：新仪器装箱出厂，配套附带 1 个专属质控 U 盘。

1. 将原装 U 盘插入 PC（例如盘符为 `E:\`）。
2. 在终端执行一步到位命令：
   ```bash
   python qc_video_builder_final.py \
       --source "D:\QC-Raw-Videos" \
       --output "E:\" \
       --device-id "ISPERM-DEV-3A8F91B2-C4D5E6F7" \
       --usb-id "USB-HW-090C-1000-AA0401270001"
   ```
3. 制作完成！此时 `E:\` 盘内已自动生成全部加密视频与专属授权 `device_binding.lic`，贴上出厂标签即可随箱发货。

---

### 场景 B：通用质控库批量制作（后续按需独立绑定）
> **适用**：生产车间提前制作好 100 个通用的加密视频 U 盘备货。

1. 批量运行标准制作命令（无需传设备参数）：
   ```bash
   python qc_video_builder_final.py \
       --source "D:\QC-Raw-Videos" \
       --output "E:\"
   ```
2. 此时 U 盘已有完整加密的视频，但尚未绑定具体仪器。备货入库。

---

### 场景 C：已售仪器远程升级 / 后期加购（独立签发绑定凭据）
> **适用**：
> 1. 医院老客户购买了 QC 视频包；
> 2. 销售将通用的备货 U 盘拿出来，需快速绑定给该客户的特定仪器；
> 3. 客户发来仪器屏幕上的设备编号。

无需重新耗时加密 30 张图片，只需使用 `qc_device_binder.py` 签发绑定文件（**耗时小于 0.1 秒**）：

```bash
python qc_device_binder.py \
    --device-id "ISPERM-DEV-3A8F91B2-C4D5E6F7" \
    --usb-id "USB-HW-090C-1000-AA0401270001" \
    --output "E:\" \
    --customer "北京协和医院生殖中心"
```

该命令会在 U 盘根目录下生成一个仅 1KB 的 `device_binding.lic` 文件，直接快递给客户即可！

## 五、如何获取绑定所需的两个关键硬件 ID

### 1. 精子分析仪设备编号 (`device_id`)
* **方式 1（屏幕查看）**：升级后的 Android 主控 APP 在【系统设置】->【关于仪器】或 QC 界面右上角，会显示：  
  `设备识别码: ISPERM-DEV-3A8F91B2-C4D5E6F7`，客户可直接拍照提供。
* **方式 2（出厂扫描）**：生产线上扫码枪扫描主板 CPU 标签或通过 ADB 命令查询：
  ```bash
  adb shell getprop ro.serialno
  ```

### 2. 采购原装 U 盘物理芯片序列号 (`usb_id`)
公司采购的工业级/品牌 U 盘，每枚芯片内部都有独一无二的出厂固件序列号（即便格式化 FAT32 也绝不会改变）：
* **Windows 命令行查看**：
  在 PowerShell 执行：
  ```powershell
  Get-PnpDevice -Class DiskDrive | Select-Object FriendlyName, InstanceId
  ```
  即可看到类似：`USBSTOR\DISK&VEN_SMI&PROD_USB_DISK&REV_1100\AA0401270001&0`，提取芯片序列号为 `AA0401270001`。
* **或使用标准格式**：
  格式：`USB-HW-[VID]-[PID]-[SERIAL]`（例如 `USB-HW-090C-1000-AA0401270001`）。若不确定 VID/PID，只需填入芯片硬件序列号 `AA0401270001` 即可，Android 端会自动匹配后缀。

## 六、U 盘最终根目录标准结构规范

制作完成发给客户的 U 盘根目录结构如下：

```
U 盘根目录 (例如 E:\)
├── device_binding.lic         <--- [关键] 一对一专属绑定授权凭据 (官方数字签名)
├── README_QC_USB.txt          <--- 给医院操作人员的使用指南说明
└── QC-Video/                  <--- 质控视频主文件夹
    ├── license.dat            <--- 视频包全局防伪签名凭证
    ├── manifest.dat           <--- 各视频包哈希与版本清单
    ├── Video-1/
    │   ├── license.dat        <--- Video-1 独立签名 (解耦支持单包增删)
    │   ├── meta.dat           <--- 视频元信息
    │   ├── 0001.qcv           <--- 经 AES-256-GCM 加密的图片帧
    │   ├── 0002.qcv
    │   └── ... (共 30 帧)
    └── Video-2/
        ├── license.dat
        ├── meta.dat
        └── ... (共 30 帧)
```

## 七、常见问题与异常排查 (FAQ)

### Q1：客户把整个 U 盘文件拷进自己的普通 U 盘，插上去能用吗？
**答：绝对不能。**  
Android 端会实时读取当前插入 U 盘主控芯片出厂硬件 Serial。普通 U 盘的芯片序列号与 `device_binding.lic` 中经 RSA 数字签名的序列号不符，APP 会弹窗报错：  
`【介质克隆拦截】检测到非原装授权 U 盘！请插入由官方配套发货的原装加密 U 盘。`

### Q2：某医院有两台我们的仪器，质控 U 盘插错机器会怎样？
**答：友好拦截提示。**  
APP 会弹出明确提示：  
`此 QC USB DISK 未授权用于本仪器，请使用分配给本仪器的 QC USB DISK。`  
`(当前仪器: ISPERM-DEV-AAAA，授权仪器: ISPERM-DEV-BBBB)`，提醒医护人员换回对应的 U 盘。

### Q3：以后给客户增加一组新的 `Video-3`，还需要重新绑定仪器吗？
**答：不需要！**  
绑定凭据针对的是【该台仪器】和【该枚 U 盘】。后续若有新增视频，只需将官方生成的 `Video-3` 文件夹复制到该 U 盘的 `QC-Video/` 目录下，并替换 `QC-Video/manifest.dat` 与 `QC-Video/license.dat` 即可。`device_binding.lic` 永久有效。

### Q4：公司签名私钥 `company_signing_rsa_private.pem` 能放进 U 盘发给客户吗？
**答：绝对严禁！**  
私钥是公司唯一的最高安全凭证，**只能保存在公司受控研发服务器或生产电脑上**。Android 分析仪内部只存有公钥（`COMPANY_PUBLIC_KEY_B64`），公钥只能用来核验签名，完全无法逆向推导私钥，即便分析仪被逆向破解也绝无伪造授权的风险。
